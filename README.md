## Installation

Clone this repository

```bash
git clone https://github.com/odiioddong/coding-collective-clone.git
```

Go to project directory

```bash
cd coding-collective-clone
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build production

```bash
npm run build
```
